# 交付前自查清单

用户原话：「你改完先自查一遍」。写 `<项目>/SELFCHECK.md`：验证了什么、怎么验证、**没验证什么**（诚实，原片 PACING_V3B.md 有「Intentionally imperfect」一节）。

## 内容
- [ ] 校准表无 `wrong`；`extension` 旁白已点名来源
- [ ] 术语全工程统一（`rg 旧词` = 0，包括画面标签、脚本、字幕）
- [ ] 关键问句只出现一次（`rg '你注意到了吗' story.py`）
- [ ] 用户锁定的句子逐字一致（落定、揭示、口误）

## 声音
- [ ] `asr_check.py` 无 `??`，或每个 `??` 已人耳确认
- [ ] 多音字/「X地」结构逐个过耳
- [ ] 每个衔接截 8s wav 听（`ffmpeg -ss <t-4> -t 8 -i out/mix.wav qa/ear/<名>.wav`）；呼吸处没有音乐涌起
- [ ] 已删除的桥接句不在混音里（原片用互相关 xcorr 验证 ≈0.02–0.04）
- [ ] 问句后约 2s 近静音；结尾无旁白，最后 0.5s 数字静音
- [ ] LUFS ≈ -16，true peak < -1 dBTP

## 画面
- [ ] `stills.py` 联系表逐张看：每场景、每句中点、每次母题
- [ ] 字幕区 y 940–1060 无画面元素；画面写字的场景没有重复的底部字幕
- [ ] 口误字幕时刻抽帧确认（快闪的取 at+frames/2 帧；hold 的取句中）
- [ ] `render.py scan` 母题次数＝设计次数；母题在揭示前从未被旁白点名
- [ ] 抖动只在设计的窗口：在非窗口时刻连抽两帧（相差 1/30s）做差，线条应完全一致
- [ ] 结尾序列抽 5–6 帧（落定定住/淡出/门渐入/静持/开门中/全黑）
- [ ] 母带、分享版时长一致；分享版 <100MB 且 faststart

## 流程
- [ ] 所有意见**一次性**改完（对照用户本轮全部消息逐条打勾），不是一点点改
- [ ] 旧版本目录未被改动（`ls -la --time-style=full-iso` 看 mtime）
