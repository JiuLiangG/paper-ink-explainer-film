# 叙事装置

以《精神分析的本质》为样本（story.py 场景顺序：cold → title → ice/slip/gap → repress/nle/comp/dream/displace → couch/assoc/method → turn/montage/reveal → end）。

## 骨架（5 分钟版）
| 段 | 约时长 | 功能 | 原片 |
|---|---|---|---|
| 冷开场 | 10–15s | 一个**具体的历史/生活画面**，不是标题 | 「一百多年前，维也纳。一位医生让病人躺下，自己却坐到了病人看不见的地方……想到什么，就说什么。」 |
| 标题 | 3.4s | 手写标题 + 下划线，无旁白 | 精神分析的本质 |
| 第一幕：纠正误解 | ~60s | 先画出大众的图，再指出它错在哪 | 冰山图（三层：意识/前意识/无意识）→「它恰恰弄错了」→ 议长口误例 → 「缝」 |
| 第二幕：机制 | ~90s | 核心机制逐个演示，每个配一个物 | 压抑≠删除（剪辑时间线删素材又回来）→ 症状＝妥协形成 → 梦工作（凝缩/移置） |
| 第三幕：方法 | ~70s | 这门学问「怎么做」 | 躺椅、自由联想、均匀悬浮注意、移情 |
| 转折 | ~4s | 叙述者自己转向观众 | 「有一件事，我一直没说。」扶手椅转过来 |
| 揭示 | ~30s | 回放证据，点出母题，问一句 | 门 ×1…×10＋口误清单 →「我从来没有提过它。」「你注意到了吗？」→ 静默 ~2s → ×11 |
| 落定 | ~20s | 三句话说清「本质」，画面写字 | 「精神分析，相信这样一件事：」… |
| 结尾 | ~11s | **无旁白**，一个动作 | 只剩一扇红门渐入 → 缓开 → 推入全黑 → 空气声 → 静音 |

## 装置 1：隐藏母题（×N）
- 一个小红物在前面所有场景里出现 N 次（原片 11 次红门：诊室右缘、冰山底、议长身后墙、纸页角涂鸦、被删的素材、雨窗倒影、字幕碎片拼成门形、凝缩脸的嘴、移置房间后墙、梦→门一瞬间、时间线上的红迹）。
- 规则：出现在边缘或一闪而过；镜头移动把它挤出画面；**旁白从不提**；揭示时回放 ×1…×N-1，再说「连这次回放，也漏了一扇」点出第 N 个——观众二次被抓。
- 主题就是装置：原片讲「没说出口的东西仍在诉说」，母题本身就是一个一直没被说出口、却一直在场的东西。换题目时，让母题和主题同构。

## 装置 2：字幕口误
- 配音说 A，字幕显示 B（`slip=`）。快闪（9–11 帧）几处 + **整句持续**一处（`hold=True`）。
- 原片：「简单→危险」（10 帧）、「这些细节→那扇门」、「删掉了，就忘了」字幕整句显示「删掉了，就忘不了」、「我们→我门」、「分析师→你」。
- 用户锁定的规则：b07 的字幕**全程**「忘不了」而声音「忘了」——持续的错比一闪的错更能被注意到；揭示时逐条念出「“忘了”，写成了“忘不了”」与之一致。
- 口误内容要指向母题或主题（门/危险/你），不是随机错字。

## 装置 3：自指
- 用片子自己的媒介演示概念：压抑＝剪辑时间线上删掉一段素材，后来它从别的轨道（字幕轨红块、倒放的音频波形）回来；倒带声用片子自己的旁白倒放加速。

## 问句，不是判语
- 揭示句定稿：「我从来没有提过它。」「你注意到了吗？」——删掉了「是你看见的」（用户：太绝对）。
- 「你注意到了吗？」全片只出现一次（用户发现疑似重复，要查）。
- 落定用「X，相信这样一件事：」开头，把本质说成一种立场，再用两句展开；不说「所以你要……」。
- 删掉了「你是分析师/病人」「轮到你说了」这类跳出式角色扮演（校准：把关系卡通化成一上一下）。

## 开放式结尾
- 落定字定住 1.0s → 淡出 0.75s → **只**渐入一扇红门 1.25s（不回放片头诊室）→ 闭门静持 1.0s → 缓开同时推镜入门内 3.9s → 全黑 1.0s → 空气声后静音 2.5s。共约 11.4s，无旁白、无金句卡。
- 不做：门后是诊室、「轮到你说了」、说教收尾、颤抖当高潮。

## 承接
- 概念块之间靠**已有的承接句**＋约 1s 画面呼吸。原片的承接都在下一句开头：「弗洛伊德记下过这样一个例子」「症状，就是这样回来的」「这就是分析师的第二条」。
- 不插「举个例子。」「那它回来，变成什么？」「所以分析师，是这样听的。」——v3 加过、用户嫌「更诡异了」、v3b 全删。

## 写稿要点
- 每句一个意思；长句用逗号切成字幕可承载的块（≤19 字/屏）。
- 每段落给一个**具体的物**可画（冰山、议长、剪辑时间线、茶杯、躺椅）；画不出物的段落先别写。
- 数字、术语、人名准确；引用扩展学派（拉康）要点名「后来，拉康说……」。
