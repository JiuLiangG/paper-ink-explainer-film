# 学术校准（对照权威教材）

原片做法见 `/workspace/psychoanalysis-film-v2/calibration.md` 与 `brenner_pacing_audit.md`。

## 锚点
- **主锚**：一本经典入门教材，决定术语和主轴（原片：Brenner《An Elementary Textbook of Psychoanalysis》）。
- **辅锚**：一本当代综述，防止刻板卡通化、校正用语（原片：Shedler《That Was Then, This Is Now》）。
- 用户给的 PDF/MD 附件优先；没有就先问，再用公认教材。

## 校准表模板（写进 `<项目>/calibration.md`）
| # | 片子主张（旁白/画面原文） | 主锚依据（章节） | 辅锚 | 判定 | 处理 |
|---|---|---|---|---|---|
判定只用五种：`accurate` / `oversimplified`（可用但要注意）/ `wrong`（必改）/ `missing`（锚点书核心而片子没有）/ `extension`（超出主锚，旁白须点名来源）。

## 原片中被抓出来、后来改掉的
| 问题 | 改法 |
|---|---|
| 冰山只有两层（水面/水下＝知道/不知道） | Freud 地形学三层：意识/前意识/无意识；加一条淡的前意识水线与标签。片子要否定的是「地下仓库」隐喻，不是层数 |
| 「潜意识」「无意识」混用 | 全片统一「无意识」（Ucs 的学术通行译法），画面标签、旁白、字幕、脚本全部改 |
| 「无意识是会说话的东西」（拟人） | 改为 Brenner 语感：「不是仓库里的存货，而是一直在起作用的东西。它从你的话里露出来，尤其在话说岔了的地方。」拉康「像一门语言」保留一句作扩展并点名 |
| 结尾「你是分析师／轮到你说了」 | 删：把协作关系卡通成上下级 |
| 落定「不是挖出地下室……倾听卡住」 | 把本质收窄成技巧 → 换成三句：相信什么／没说出口的仍在诉说并在关系中重演／在重演时认出、让它被说出来而不只是被演出来（对应被压抑者回归、移情与强迫重复、回忆-重复-修通） |
| 揭示句「是你看见的」 | 太绝对 → 「你注意到了吗？」 |

## 流程
1. 写完初稿后逐句建表；`wrong` 全改，`missing` 判断是否必要（5 分钟片不求全，但核心不能缺）。
2. 改稿同时改画面标签（标签和旁白必须同词）。
3. `rg` 全工程搜旧术语确认清零（原片 `rg 潜意识` 应为 0）。
4. 交付语里简短说明「对照 X 校准了哪几处」，用户重视专业度。
